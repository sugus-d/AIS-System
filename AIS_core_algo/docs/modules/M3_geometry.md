## 输入 / 输出

| | |
|---|---|
| **输入** | ROI 网格、脊柱中线 |
| **输出** | 曲率向量、标志点坐标、高度场、分割标签、配准网格 |

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `clip_range_mean` | [-0.015, 0.025] | 平均曲率裁剪范围 |
| `clip_range_gauss` | [-0.00025, 0.00025] | 高斯曲率裁剪范围 |
| `seg_shoulder_thresh` | 0.78 | 肩部 Y 阈值 |
| `seg_lumbar_thresh` | 0.42 | 腰椎 Y 阈值 |
| `seg_pelvic_thresh` | 0.18 | 骨盆 Y 阈值 |

## 文件

- `mesh/curvature.py` — 曲率计算与可视化
- `landmarks/` — 解剖标志点（6 类检测器，各子包 core.py）
- `features/extractors/asymmetry/surface_height.py` — 表面高度
- `mesh/roi/segmentation.py` — 解剖分割（Y 高度阈值）
- `parameterization/` — 调和映射参数化配准（替代旧 TPS）
