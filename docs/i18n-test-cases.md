# 多语言（简体中文 / 繁体中文）测试用例

> 覆盖范围：主应用 `client` 全部界面文案。标注平台、后端 API 返回的错误消息不在本轮范围（见文末）。
> 校验辅助脚本：`node scripts/check-i18n-keys.mjs`（静态 key 完整性，当前 376/376 通过）。

## 0. 测试前提
- 启动打包版 `AIS.exe`（登录态为会话级，每次打开需登录；若之前勾选「记住密码」，账号密码已回填）
- 首次打开：默认语言 = 系统语言（系统为 `zh-TW/zh-HK/zh-Hant` → 繁体，其余 → 简体）；也可在登录页右上角手动切换

## 1. 语言切换入口（3 处）
| 用例 | 操作 | 预期 |
|---|---|---|
| 1.1 登录页切换 | 登录前点右上角「繁體」 | 登录页全部文案立即变繁体（AIS 篩查系統 / 密碼 / 記住密碼…），按钮高亮「繁體」 |
| 1.2 Header 切换 | 登录后点 Header 右侧「简体/繁體」 | 全站文案即时切换 |
| 1.3 设置页切换 | 个人设置 → 语言偏好卡片 | 可切换；卡片说明「默认跟随系统语言…」随语言变化 |
| 1.4 切换即时性 | 繁体下浏览受检者详情页 → 切简体 | 无需刷新，页面文案立即变简体 |

## 2. 语言检测与持久化
| 用例 | 操作 | 预期 |
|---|---|---|
| 2.1 持久化 | 切繁体 → 关闭客户端 → 重开 | 仍是繁体（偏好存 localStorage） |
| 2.2 跟随系统 | 清除偏好（删除 localStorage `ais_locale`）→ 系统语言设为繁体 → 重开 | 显示繁体；系统语言非繁体 → 简体 |
| 2.3 语言切换按钮文字 | 任意语言下 | 按钮始终显示「简体」「繁體」（各语言自身名称，不随语言变化） |

## 3. 分页面用例（每页在简/繁两种语言下核对）
### 3.1 登录页（login）
- 标题/副标题/账号/密码/记住密码/登录/忘记密码提示
- 错误提示：空账号密码提交 → 「请输入账号和密码。」/「請輸入帳號和密碼。」
### 3.2 工作台（dashboard）
- 标题/副标题/数据概览/快捷操作/四个指标卡（受检者总量/待分析/已完成分析/待上传文件）/三个操作入口
### 3.3 受检者管理（cases）
- 标题/搜索占位/全部状态/三种排序/升降序/列表标题/共 N 条/表头 7 列/查看详情/空态/加载中
- 状态标签：待上传/待分析/分析中/审核中/已通过/待修改（enums）
- 性别列：男/女
### 3.4 受检者详情（caseDetail）
- 基本信息两列（姓名/性别/年龄 岁/生日/身高 cm/体重 kg/身份证/电话/既往病史）/编辑资料
- X 光结果卡（上传 X 光/空态/缩略图时间/删除确认弹窗「确定删除 X 光图片「xx」吗？此操作不可恢复。」）
- 筛查报告（说明/新建报告/表头 10 列/查看 3D 收起 3D/上传时间提示「上传时间：… 左键旋转/滚轮缩放/右键平移」/查看报告/重新分析 开始分析 分析中）
- **分析结果列**：Cobb 角取整 + 严重程度（后端数据映射）：正常/轻度/中度/严重 → 繁 正常/輕度/中度/嚴重；未分级 → 未分級；颜色 绿/黄/橙/红
- 上传弹窗（新建报告（上传扫描）/上传 X 光/PLY 文件/X 光图片（可多选）/已选择 N 个文件/格式校验提示）
### 3.5 报告详情（report）
- 报告编号/受检者/返回/重新分析/保存/另存为 PDF/导出中
- 状态横幅（审核中/审核退回/已通过/分析中）
- 受检者信息 9 项/算法输出 5 项 + AIS 严重等级（正常/轻度/中度/严重）
- 诊断意见（编辑/取消编辑/临床诊断/随访建议/治疗方案）
- 影像结果 4 图 + X 光影像（点击放大/暂无）
- 运行数据/文件信息 6 项
- 另存为 PDF → 原生对话框标题（简体「另存为 PDF」/繁体「另存為 PDF」）、默认文件名（AIS报告/AIS報告）、过滤器（PDF 文档/PDF 文件）；生成的 PDF 内容为当前语言
### 3.6 数据统计（stats）
- 标题/刷新/重试/四个指标/三张图表标题与提示
- **AIS 分级图例**（后端英文 Normal/Mild/Moderate/Severe → 本地化）：简 正常/轻度/中度/严重；繁 正常/輕度/中度/嚴重
### 3.7 个人设置（settings）
- 标题/个人资料（账号/角色/姓名/科室）/密码管理 4 项/保存提示/语言偏好卡片
- 保存个人资料后刷新页面：Header 姓名/科室显示新值（sessionStorage 一致）
### 3.8 用户管理（users）
- 标题/新增用户/共 N 位用户/刷新列表/表头 7 列/角色列（系统管理员/机构管理员/临床操作员）/状态（正常/已禁用）/操作（编辑/禁用 启用/删除）
- 新建/编辑弹窗全部字段与校验提示（用户名规则/姓名必填/密码 12 位/仅系统管理员可修改角色）
- 删除确认弹窗
### 3.9 系统设置（adminSettings）
- 标题/应用配置（名称/时区/保存设置）/本地备份（创建备份/暂无备份/恢复/恢复确认弹窗/保存成功提示）
### 3.10 帮助中心（help）
- 标题/副标题/三个 FAQ 问答
### 3.11 通用组件
- DataTable：加载中/暂无数据/共 N 条记录，第 x/y 页/上一页/下一页
- Header：导航三项/个人设置/系统设置/用户管理/退出登录/未登录兜底

## 4. 边界与已知保留项（两种语言下行为一致，不视为缺陷）
- 代码注释、控制台 `console.error` 日志
- 后端**数据值**比较逻辑（性别 `'男'/'女'`、`aisLevel === '正常'` 等判断，翻译会破坏匹配）
- 用户输入数据：姓名、科室、医生、备注、诊断意见、文件名、X 光图片名
- 日期/时间数字格式（`2026-08-28 14:30`）
- 指标英文名（Asymmetric Index、Cobb Angle 等算法术语）、文件单位（MB、cm、kg）
- 语言切换按钮自身文字「简体/繁體」
