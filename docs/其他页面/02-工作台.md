# 工作台

## 1. 页面范围

- 快捷操作入口
- 数据概览看板
- 待办提醒
- 状态监控

## 2. 页面定位

工作台是登录后的默认首页，聚合关键业务状态和高频入口，支持快速处理待办。

## 3. 页面结构

### 3.1 快捷操作入口

这实际上是所有页面公用的TopBar，包含

##### 通用入口：

- 工作台
- 受检者管理
- 报告管理
- 任务管理
- 数据统计


##### 设置入口：

从用户头像点开弹出下拉菜单，管理员界面标*，管理员入口仅管理员可见，普通用户侧需完全隐藏

- 个人设置
- 系统设置*
- 用户管理*

### 3.2 数据概览看板

- 普通用户仅查看本人操作范围内的受检者、上传、分析、报告等数据
- 管理员查看全系统受检者、上传、分析、报告等汇总数据，并支持按用户、科室等维度筛选
- 看板需支持展示关键统计摘要，如受检者总量、待分析数量、分析成功数量、异常任务数量等

### 3.3 待办提醒

- 已上传未建档
- 已建档未上传
- 已上传未分析
- 分析异常待处理

管理员可查看全系统通用待办及管理员待办，如用户信息修改审核、删除审核、接口异常提醒，普通用户仅查看本人范围内的通用待办

### 3.4 状态监控

- 上传进度
- 算法分析进度
- 任务执行状态
- 接口连接状态
- 任务执行异常提示

## 4. 关键规则

- 展示内容受角色权限约束
- 待办需与任务系统状态实时同步
- 快捷入口按角色动态展示
- 看板、待办、状态监控的数据口径需与任务页、统计页、受检者管理页保持一致
- 待办点击后应直接跳转至对应业务页面，并保留筛选上下文
