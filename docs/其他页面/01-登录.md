# 登录

## 1. 页面范围

- 账号密码登录
- 密码找回
- 首次登录绑定引导
- 登录态与异常提示

## 2. 页面定位

登录页是系统统一入口，负责身份认证与初始安全配置，是后续页面权限分发的起点。

## 3. 页面结构

### 3.1 账号登录

- 表单字段：账号、密码、记住账号
- 登录成功后统一进入工作台，管理员与普通用户基于角色展示不同的数据范围、待办内容和管理入口
- 页面底部展示系统版本、版权信息等基础系统信息，测试版本额外提示默认账号密码
- 若账号被禁用、删除或角色权限异常，需在登录阶段直接给出明确提示

### 3.2 密码找回

1. 用户选择邮箱或手机号找回
2. 系统发送验证码
3. 验证通过后重置密码
4. 成功后返回登录页

异常场景：

- 未绑定邮箱/手机号时，不允许使用找回密码能力，提示联系管理员
- 验证码失效、校验失败、重置次数超限时，需给出明确错误提示

### 3.3 首次登录引导

- 首次登录必须绑定邮箱或手机号（至少一种）
- 绑定完成前，仅允许停留在绑定引导流程，不得访问受检者管理、文件上传、算法调用等核心页面

## 4. 关键规则

- 登录成功后按角色分发页面和数据权限
- 密码找回依赖已绑定邮箱/手机号
- 登录、退出、重置、绑定变更需记录日志
- 账号必须至少绑定邮箱或手机号之一，未绑定用户限制核心功能使用
- 密码复杂度、有效期、重置规则受系统设置统一控制
